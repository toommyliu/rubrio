# Rubrio

Grade paper assignments on your own machine, Gradescope style. Create a course and an assignment, print it, scan the stack, match names, grade one question at a time across the class, and export. A local model can transcribe answers or draft grades for you to review, but nothing needs it.

A spec is currently outlined in [docs/design.md](docs/design.md).

## What does CPU stand for? (10 points)

Answer: Central Processing Unit

Rubric:
- Correct
- One word wrong, such as Computer Processing Unit (-5)
- Describes what a CPU does instead of naming it (-5)
- Incorrect (-10)

### What is 2 to the power of 5? (10 points)

Answer: 32

Rubric:
- Correct (+10)
- Power of 2 off by one, such as 16 or 64 (+6)

### Convert binary 1010 to decimal. (15 points)

Answer: 10

Rubric:
- Correct
- Missed one bit, such as 8 or 2 (-5)
- Copies the binary digits as a decimal number (-10)
- Incorrect (-15)

## In a few words, what is a variable? (20 points)

Answer: A named place that stores a value
Answer: A name that refers to a value

Rubric:
- Correct
- Mentions storing data but not the name (-8)
- Only says it is a value (-12)
- Incorrect (-20)

## Write a Python expression for the last item of the list `xs`. (20 points)

Answer: `xs[-1]`
Answer: `xs[len(xs) - 1]`

Rubric:
- Correct
- Right idea, wrong index, such as `xs[len(xs)]` (-10)
- Another language's syntax, such as `xs.last` (-10)
- Incorrect (-20)

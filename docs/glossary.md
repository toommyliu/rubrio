# Glossary

Use these words in code, the UI, the CLI, docs and conversation. Don't use the words in the last column. If something new needs a name, add it here first.

## Setup

| Term | Meaning | Not |
|---|---|---|
| home | The folder that holds all of Rubricate's data, `~/Rubricate` by default | workspace, library, data dir |
| course | A class in one term, with a roster, staff and assignments. Named by a slug like `cs101-f26` | class, section |
| short name | A course's or assignment's name in links, like `cs101-f26`. A slug in code | slug (in the UI) |
| roster | The course's list of students | class list |
| student | Someone on the roster, identified by their sid | |
| sid | A student's ID number | student number |
| staff | The instructors and TAs on a course. Only matters in hosted mode | |
| grader | Whoever is grading, whatever their role | TA (unless the role is meant), marker |
| local mode | The web app on 127.0.0.1 with no sign-in | |
| hosted mode | The web app with Google sign-in, for several graders | |

## The assignment

| Term | Meaning | Not |
|---|---|---|
| assignment | One thing students hand in: a quiz, exam, worksheet. Named `course/assignment`, like `cs101-f26/quiz-5` | exam, test, quiz (as the general word) |
| assignment file | The markdown file that defines an assignment | QA file, spec |
| version | One variant of an assignment, with its own questions and template. Versions share nothing | variant, form |
| question | A `##` heading in the assignment file. Also covers parts where the difference doesn't matter | problem, item |
| part | A `###` heading under a question. A question with parts is graded part by part | subquestion |
| points | What a question or part is worth | marks, weight |
| answer key | The `Answer:` lines and `[x]` choices. What a correct response looks like | solution, correct answer |
| choice | One of the options in a multiple-choice question | answer option |
| blank | A `____` in a prompt, printed as a box to write in | |
| answer space | The empty room left under a question for writing | |

## Templates and the outline

| Term | Meaning | Not |
|---|---|---|
| template | The blank PDF of one version, as printed. Generated by Rubricate or made elsewhere | blank, exam PDF |
| label | The printed number that starts a question on the template, such as `1.` or `a)` | header |
| outline | All the boxes on an assignment's templates | region map |
| box | A rectangle on a template page that belongs to one question, or to the name or ID field. A question can have several | region, bbox, segment, band |
| suggested box | A box Rubricate placed from its own layout or from the printed labels, before anyone edited it | |

## Scans

| Term | Meaning | Not |
|---|---|---|
| scan | A PDF of filled-in pages that you upload | bundle, batch |
| scan page | One page of a scan | |
| alignment | Matching a scan page to its template page. It gives the page's identity, its rotation and the transform used for cropping | registration |
| submission | One student's pages for one assignment, grouped from scan pages | paper, booklet |
| extra page | A scan page that matches no template page, such as scratch paper | extra work |
| flag | A problem with a submission's pages that needs a person: missing page, repeated page, out of order, mixed versions or extra page | warning, issue |
| response | What one student wrote for one question | answer |
| crop | The image of a response: what falls inside a question's boxes once the scan page is aligned | snippet |

## Names

| Term | Meaning | Not |
|---|---|---|
| name matching | Linking each submission to a student on the roster | identification |
| suggested match | A student Rubricate proposes for a submission because they clearly beat the runner-up | |
| confirmed match | A match a grader has accepted or picked | |

## Grading

| Term | Meaning | Not |
|---|---|---|
| rubric | The list of rubric items for one question | |
| rubric item | One checkbox on a rubric, with a description and points. Any number can apply to a response | criterion, category, rubric option, rubric label |
| negative scoring | A question whose rubric items are zero or negative. It starts at full points | deduction mode |
| positive scoring | A question whose rubric items are zero or positive. It starts at 0 | |
| grade | The result for one response: the rubric items applied, an adjustment and a comment | mark |
| score | The points a grade is worth. Always computed, never stored | |
| adjustment | Points added or taken off one grade outside the rubric | override, manual score |
| comment | Free text on one grade, shown to the student | note |
| feedback PDF | The PDF exported for one student: their scan pages, then each question's score, rubric items and comment | |
| ungraded | A response with no grade | |
| draft | A grade the model wrote that no person has confirmed | suggestion, AI grade |
| confirmed | A grade a grader saved or accepted | final, reviewed |
| revision | A counter on each grade. A save based on an old revision is rejected | version (that word means something else) |
| event | One entry in the history log, used for undo | |

## The model

| Term | Meaning | Not |
|---|---|---|
| model | The local model at the endpoint in `config.toml` | LLM, AI, provider |
| transcription | The text the model read from a response | OCR text, transcript |
| autograde | Having the model draft grades | AI grading |
| evaluation | How many drafts graders confirmed unchanged and how many they changed | |
| job | Background work with progress, such as processing a scan, transcribing or autograding | task |
